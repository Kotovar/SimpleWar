# Устройство проекта

Клиентское приложение: React 19, TypeScript, Zustand с Immer, Canvas 2D.
Для карты используются simplex-noise и pathfinding. Сборка, тесты, линтинг
и форматирование запускаются через Vite+. Отдельного серверного приложения
в репозитории нет.

## Где искать код

| Каталог                     | Ответственность                                                              |
| --------------------------- | ---------------------------------------------------------------------------- |
| `src/app`                   | Корневой интерфейс, инициализация партии и событий, запуск хода ИИ           |
| `src/widgets/map`           | Слои Canvas, отрисовка, обработка кликов                                     |
| `src/widgets/game-controls` | Настройки, показатели, меню найма и строительства                            |
| `src/widgets/start-game`    | Генерация карты и стартовые объекты                                          |
| `src/features`              | Строительство, найм, бой, ходы, поиск пути и выбор объектов                  |
| `src/entities`              | Zustand-хранилища карты, настроек, юнитов, зданий, экономики, фазы и журнала |
| `src/shared/config`         | Типы, баланс, названия, параметры карты и экономики                          |
| `src/shared/lib`            | Общие расчёты, проверки стоимости, шина событий                              |
| `src/shared/ui`             | Общие диалоги                                                                |

Структура следует слоям FSD; алиасы `@app`, `@widgets`, `@features`, `@entities`,
`@shared` настроены в TypeScript и Vite. Срезы экспортируют API через `index.ts`.
Игровые события связывают появление/уничтожение объектов с населением и победой.

Игровые действия — команды с явными параметрами: `move`, `attack`, `build`,
`spawn`, `nextTurn`. Каждая принимает действующего участника (`actor`), ID
исполнителя, тип и цель, не читает выбор интерфейса и возвращает
`CommandResult`: успех или отказ с кодом и русским текстом без скрытых сведений.
Отказ ничего не меняет. Интерфейс и ИИ вызывают одни и те же команды.
Итог каждой команды попадает в журнал `entities/journals` через `runCommand`:
успех — в события, отказ или исключение (сбой) — в ошибки; повтор ошибки подряд
склеивается, объём ограничен, журнал очищается при новой партии. Последствия —
гибель юнитов, разрушение зданий, выбывание и конец партии — записывает
`app/system/journal.ts` по игровым событиям. У каждой записи есть `visibleTo`:
свою команду видит только участник, гибель и разрушение — обе стороны,
выбывание и исход — все. Обычный журнал участника (`getVisibleRecords`) берёт
только видимые ему записи без технических деталей, полный — для отладки.
Ошибка старта идёт тем же путём.

Режим отладки включается в «Меню»: исключения (бесплатная стройка, стройка
за один ход, бесплатный найм) задаются по участнику и применяются внутри
команд, базовая конфигурация не меняется. Хранилища подключены к Redux DevTools
через `withDevtools`, только в dev и при установленном расширении.

## Команды из package.json

| Команда             | Назначение                        |
| ------------------- | --------------------------------- |
| `pnpm dev`          | Сервер разработки                 |
| `pnpm type-check`   | Проверка TypeScript без сборки    |
| `pnpm lint`         | Oxlint исходников                 |
| `pnpm react-doctor` | React Doctor                      |
| `pnpm build`        | TypeScript и production-сборка    |
| `pnpm fsd-check`    | Проверка структуры через Steiger  |
| `pnpm preview`      | Просмотр готовой сборки           |
| `pnpm format`       | Oxfmt с перезаписью всего проекта |

После клонирования: `vp install` или `pnpm install`.
Тесты: `pnpm test` — весь набор, `pnpm test:unit` — unit,
`pnpm test:integration` — сценарии взаимодействия хранилищ и событий.
Состояние партии находится в `entities/games`, запуск — в
`widgets/start-game/initializeGame.ts`. Для изменений документации достаточно
проверить ссылки и форматирование только затронутых Markdown-файлов.

Источники: [package.json](../package.json), [tsconfig.json](../tsconfig.json),
[vite.config.ts](../vite.config.ts), [события](../src/shared/lib/events.ts).
