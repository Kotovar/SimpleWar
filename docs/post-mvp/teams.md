# P02. Постоянные команды

Ветка: `feat/teams`. [Правила](../mechanics.md#команды-и-союзы-p02).

В обычном меню каждой стороне по умолчанию назначена отдельная команда 1–4.
Выбор команды стоит рядом с цветом. Для игры за себя выбирается отдельная команда.
Поддерживаются 2×1, 2×2 и смешанная партия команды с одиночными участниками.
Настройки сохраняются, старые партии загружаются без команд.

Общий обзор и память включены по решению пользователя 2026-10-22. Лекарь
лечит союзников; транзит сквозь союзные войска разрешён. Доход, население,
исследования и приказы остаются личными. Обычный огонь по союзникам запрещён;
осада по клетке по-прежнему поражает всех наземных. Обмена ресурсами и смены
союзов нет. В режиме тестирования баланса остаются независимые стороны.

Потеря ратуши выводит только её владельца. Человек наблюдает за союзниками;
если команда побеждает позже, победа засчитывается и ему. ИИ выбирает только
врагов, лечит союзника и защищает союзную ратушу правилом M07 при отсутствии
срочной угрозы собственной базе.
