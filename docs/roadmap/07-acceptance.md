## S21. Набор сценариев, баланс и производительность

Зависимости: S17–S20. Запуск логики — без Canvas; поведение интерфейса — в браузере.

### Обязательные группы сценариев

| Группа        | Проверяемый результат                                                                  |
| ------------- | -------------------------------------------------------------------------------------- |
| Законность    | Чужой ход/владелец, цена, лимит, путь, дальность, видимость проверяются общей командой |
| Атомарность   | Отказ не списывает ресурсы/очки, не создаёт половину объекта                           |
| Ходы          | Доход и исследования ровно один раз; новый юнит не действует сразу                     |
| Исход         | Оба владельца могут победить; после `gameOver` нет новых действий                      |
| Генерация     | Сид воспроизводится, базы/ресурсы доступны, плохая карта не принимается                |
| Знания        | Видимость симметрична, память устаревает, пустое место опровергает контакт             |
| Честность ИИ  | Два мира с одинаковым наблюдением дают одинаковое решение до новой информации          |
| Экономика     | Выбор золота/дерева по дефициту; потеря рабочего/фермы не ломает состояние             |
| Строительство | Не перекрывается последний известный выход/место найма; тупик разрешается              |
| Разведка      | Находит неизвестного врага и ресурс, не ходит к базе по знанию генератора              |
| Наступление   | Собирает группу, атакует подходящую цель, не ждёт бесконечно                           |
| Оборона       | Реагирует на налёт, сохраняет рабочих, может отозвать ударную группу                   |
| Тактика       | Фокус, контрроли, дистанция стрелка, прикрытие осады, осмысленный отход                |
| Исследования  | ИИ выбирает полезное, при угрозе сохраняет резерв; бонус не удваивается                |
| Сохранение    | Продолжение сохраняет мир, память и решения; ошибки не уничтожают слот                 |
| UI            | Ни карта, ни карточки, журнал, анимации или миникарта не раскрывают скрытого врага     |

Для каждого G/W/M/A/R/P/C/O/T-ID из каталога добавить строку в матрицу:
`ID → путь к сценарию → ожидаемое решение → результат`. Общие сцены могут
проверять несколько правил, но одного «ИИ сходил без ошибки» недостаточно.
На каждое правило нужны позитивный и негативный случай; конфликты приоритетов
проверять отдельно для обороны/экономики, отхода/атаки, разведки/рейда.

### Прогоны партий и настройка баланса

- Набор из 20 зафиксированных сидов × 3 профиля ИИ × 2 стартовые стороны:
  **120 автоматических матчей** с фиксированным проверочным противником.
  Дополнительно зеркальные встречи профилей — для поиска асимметрий.
- Включить отдельные сценарии намеренной победы игрока и поражения пассивного
  игрока. Внутренние матчи ИИ не заменяют ручную проверку игры человеком.
- Ограничение прогона: предложение 200 полных ходов. Достижение лимита —
  диагностический тайм-аут, не автоматически успешная ничья и не правило игры.
- Собирать победителя/длительность, доходы, найм, потери, открытия карты,
  переключения стратегии, отказы команд, зависшие задачи и длительность хода ИИ.
- На зафиксированном наборе не должно быть зависаний, незаконных действий,
  повторяемых тупиков экономики/пути и тайм-аутов. Причины длительных матчей
  разбирать отдельно: непроходимость, ожидание сбора, чрезмерная защита, баланс.
- У каждого нового типа и исследования должна быть ситуация, где он полезен;
  не должно быть одного выбора, безусловно лучшего во всех сценариях.
- Предлагаемый ориентир для основной карты 30×30: 15–40 минут человеческой
  партии. Это цель настройки, не гарантированный результат до плейтестов.
- Сложность оценивать по ручным партиям; частота побед ИИ против самого себя
  не доказывает интересность или сложность игры человеку.

### Измеримые технические пределы

Зафиксировать тестовую машину, браузер, размер окна, DPR и состав сцены.
Предварительный бюджет MVP на этой машине:

- 100×100 клеток, до 60 юнитов суммарно при лимитах населения сторон,
  стресс-сцена со 100 зданиями; также проверить плотные узкие проходы.
- Pan/zoom: p95 кадра не выше 33 мс на 1280×720/DPR 1; DPR 2 проверить отдельно.
- Расчёт хода ИИ без анимаций: p95 до 2 секунд; разбиение работы не допускает
  непрерывной блокировки интерфейса дольше 100 мс. Превышение лимита команд
  завершает расчёт безопасно, фиксирует диагностику, но не считается нормой.
- 10 циклов новая игра/загрузка/сброс не оставляют старых подписок и задач;
  память после сборки мусора не растёт монотонно от партии к партии.
- Если бюджет не выполнен, сначала найти измеренный источник: повторный поиск
  пути, пересчёт всего тумана, отрисовка мира. Кэш/фоновые вычисления добавлять
  для этого источника, с проверкой актуальности данных и отмены старого хода.

**Готово:** команды тестов документированы; матрица правил и отчёт прогонов
приложены; подтверждены баланс ролей и технические пределы либо явно пересмотрены
целевые ограничения до выпуска. Известные блокирующие дефекты не замаскированы.

## S22. Выпуск MVP

Зависимости: S21. Критерии закрываются проверкой, а не наличием кода.

- [ ] Пройдены type-check, lint, build, сценарии ядра/ИИ и проверка структуры.
- [ ] С чистого старта игрок победил ИИ; в другой полной партии ИИ победил игрока.
- [ ] Все три профиля умеют нападать, защищаться и восстанавливаться после потерь.
- [ ] Реализованы и проверены все ID каталога; нет «временного» полного обзора ИИ.
- [ ] Три состояния тумана работают отдельным Canvas; нет утечек через UI/путь.
- [ ] Все 7 юнитов, 9 зданий и 5 исследований доступны и имеют игровую роль.
- [ ] Камера удобна на всём заявленном диапазоне карт; ввод совпадает с графикой.
- [ ] Силуэты/владельцы/действия читаются в бою, под туманом и на разных масштабах.
- [ ] Сохранение, загрузка, сдача и повторная партия работают без старого состояния.
- [ ] 120 прогонов и сценарии граничных случаев прошли, ручные партии записаны.
- [ ] В документации обновлены правила, численные характеристики, управление,
      команды проверки, поддерживаемые размеры и оставшиеся неблокирующие ограничения.
- [ ] Production-сборка проверена в браузере; нет блокирующих ошибок консоли.

Результат: законченная одиночная стратегия с честным расширяемым ИИ и всеми
заявленными механиками. Сам факт победы над пассивной базой MVP не закрывает.
