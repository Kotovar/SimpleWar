# S19: заключительная приёмка

03.10.2026, ветка `feat/experience-S19`, база `15cd43b` + изменения экрана
результата и обзора. Chrome headless, DPR 1, сервер текущего checkout.
Основной размер — 1280×720; результат и обзор также проверены на
1024×768 и 540×900.

## Объём проверки

Обычная партия запущена через главное меню. Затем через хранилища подготовлены
сцены 12×6, сид 77: юниты с нужными очками, здания, местность, запасы,
изученные улучшения и номер хода. Победа получена реальной атакой по ратуше,
поражение — сдачей с подтверждением. Ничья и партия без человека — отдельные
фикстуры исхода. В экономическом сценарии вторая сторона пассивна: доход,
восстановление очков и исследование продвигались настоящими переходами хода.

| Сценарий              | Проверенный результат                                                                        |
| --------------------- | -------------------------------------------------------------------------------------------- |
| Победа, сдача, ничья  | Верный исход и ход завершения; сдача требует подтверждения                                   |
| Итоги игрока          | Свои оставшиеся силы, запасы и изученные улучшения; чужое исследование не раскрывается       |
| Обзор до конца партии | Включение отклоняется, кнопки обзора нет                                                     |
| Обзор после партии    | Туман убран с Canvas и мини-карты, ранее скрытый враг выбирается ЛКМ                         |
| Карточки в обзоре     | Нет предложения задать точку сбора; чужой копейщик показывает действующий Строй              |
| Приказы в обзоре      | ПКМ, Enter, Space и F не меняют мир, знания, журнал или отладку                              |
| Возврат к итогам      | Исход сохраняется; новая игра возвращает к настройкам и очищает партию/обзор                 |
| Партия без человека   | Нет выдуманных итогов игрока, работает обзор и выбор объектов                                |
| Стройка               | Все 10 доступных рабочему типов построены через новую панель, включая частокол Инженерии     |
| Найм                  | Все 10 типов наняты из соответствующих зданий через панель                                   |
| Панели 1280×720       | Все карточки доступны без прокрутки и горизонтального переполнения                           |
| Бой и движение        | Магическая атака, лечение и полёт над водой исполнены ПКМ; физическая атака завершила партию |
| Экономика             | Постройка рудника и лесопилки, назначение рабочих через G, фактическая добыча обоих ресурсов |
| Исследование          | Инженерия запущена клавишей 3 и завершена за три настоящих своих хода                        |
| Размеры экрана        | Кнопки результата и обзора помещаются на всех трёх размерах                                  |

Все строки пройдены; ошибок Runtime нет. Приказы C1–C8, их остановки,
клавиатура и жесты отдельно описаны в [приёмке C](10-experience-c-acceptance.md).
Полные партии против ИИ и подбор баланса остаются S21–S22; эта проверка
не оценивает качество решений ИИ. Сохранение и загрузка — S20.

скрытых изменениях противника, участник не в первом слоте и снимок исследований.
