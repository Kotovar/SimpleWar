# S14a–S14b. Магия, лечение и полёт в текущем MVP

[Карта этапов](../ROADMAP.md). Выполнить после базового контента S14,
до тактики S15, исследований S16 и финальной графики S18.
Правила и числа ниже — предложения для согласования в S01.

## S14a. Типы урона, маг и лекарь

Зависимости: S03, S06, S14.

- Сначала определить общий расчёт: источник, цель, тип урона, сопротивление,
  итоговое изменение HP. Физический и магический — достаточный начальный набор;
  стихии и иммунитеты не обязательны. Защита от одного типа не защищает от всех.
- Выбрать формулу сопротивления, порядок бонусов/улучшений, округление и минимум
  урона. Правило «минимум 1» из раннего S14 пересмотреть явно, если появится иммунитет.
  Предпросмотр, фактическая атака и оценка ИИ используют одинаковые правила.
- Добавить мага с направленной магической атакой и лекаря с лечением одного
  живого своего юнита. Лечение — отдельный положительный эффект, не отрицательный
  урон: не воскрешает, не превышает maxHP и не ремонтирует здания.
- Для первого варианта — одно боевое действие на своём ходу: атака либо лечение,
  после него движение заканчивается. Отдельные мана, регенерация и кулдауны
  необязательны; если выбраны, сначала описать их цикл и сохранение в S01.
- Лечение проверяет владельца/отношение, видимость, дальность, недостающее HP,
  совместимый тип цели и действие. Пока разрешены только свои юниты;
  союзное лечение подключается по явно выбранному правилу [P02 после MVP](../post-mvp/README.md).
- Предлагаемое место найма обоих — одно новое здание «Святилище».
  Задать стоимость, хрупкость, дальность и контрмеры; маг не должен заменять
  одновременно стрелка и осаду, лекарь не должен делать отряд бессмертным.
- Показать тип урона, защиту, доступность лечения и ожидаемый эффект в карточках.
  Различать лечение, атаку и невозможную цель в подсветке.

**Подсказки:** сначала проведи прежние физические атаки через расчёт без изменения
их результата, затем добавь магический тип и только потом лечение. Сравни простые
плоские сопротивления с процентными; не нужен универсальный язык заклинаний
ради двух эффектов. Не смешивай броню, категорию цели и способ передвижения.

**Unit-тесты:** физическая/магическая защита, границы и округление, общий расчёт
бонусов; лечение полного/раненого/мёртвого/чужого/невидимого юнита, предел HP,
нехватка действий, отказ без расхода. Интеграционно — лечение после перемещения,
атака и лечение в одном ходу запрещены, сброс/загрузка не возвращают действие.

**Готово:** маг и лекарь доступны обеим сторонам, подчиняются туману и общим
командам; старый бой не сломан. Тактику ИИ завершить в S15, баланс — в S21.

## S14b. Летающий юнит и доступность целей

Зависимости: S14a и S04–S07. Наземную генерацию и туман закончить до полёта:
летающий разведчик не должен скрывать непроходимость стартов для рабочих.

- Разделить тип перемещения «земля / воздух», тип урона и перечень целей,
  которые можно атаковать. Полёт не означает магический урон или иммунитет к стрелам.
- Добавить один летающий боевой тип, например грифона; в первом варианте нанимать
  через Святилище. Это предложение роли, конкретный образ и числа выбрать в S01.
- Воздух преодолевает воду, горы и лес; согласовать проход над зданиями/юнитами
  и допустимые конечные клетки. Простой вариант MVP: пролёт над занятыми клетками
  разрешён, остановка только на клетке без другого объекта, включая воду/горы.
  Совместное размещение земли и воздуха — отдельное расширение, не скрытое правило.
- Для земли сохранить прежние запреты. Подсветка, путь, стоимость, выполнение
  команды и оценка маршрутов ИИ учитывают один профиль перемещения.
- Задать матрицу «кто поражает землю/воздух». Предложение: мечник и копейщик
  не бьют воздух; лучник, башня и маг дают доступную противовоздушную защиту.
  Для летающего типа отдельно определить атаку зданий и других летающих.
- Полёт не отменяет туман: обзор обновляется по пройденным клеткам,
  скрытый враг не становится целью. Воздушный путь не даёт наземной группе проход.
- Отобразить полёт силуэтом/тенью и значком; карточка сообщает допустимые цели.
  Нельзя оставлять недоступную для атаки цель в обычной боевой подсветке.

**Подсказки:** раздели проверку транзита и остановки до правок поиска пути.
Проверь маленькую сцену «берег — вода — берег» и занятую конечную клетку;
перед вводом отдельных слоёв занятости оцени, нужны ли они одному типу MVP.

**Unit-тесты:** наземный отказ и воздушный проход на одной карте, занятая точка
остановки, граница карты и запас движения; все пары земля/воздух в матрице атак,
неизвестный маршрут и отсутствие раскрытия скрытых целей.
Браузером проверить выбор юнита над водой, подсветку и читаемость под туманом.

**Готово:** летающий юнит преодолевает наземные преграды законно, у него есть
доступная контрмера, ИИ использует его через S15 без обхода правил видимости.

## Дополнение каталога ИИ для S15

Эти 12 правил дополняют [51 исходное тактическое правило](ai-patterns.md).
Для каждого нужны положительный, отрицательный и конфликтный сценарии.

| ID  | Условие → решение                                                                                                        |
| --- | ------------------------------------------------------------------------------------------------------------------------ |
| H01 | Свой раненый юнит доступен для лечения → выбрать наибольшую полезную прибавку с учётом угрозы и уже назначенного лечения |
| H02 | Цель вне дальности → занять безопасную клетку лечения, не обгоняя прикрытие                                              |
| H03 | Лекарь под угрозой → уйти к защите вместо рискованного лечения                                                           |
| H04 | Лечить некого → сопровождать нуждающуюся в поддержке группу, не тратить действие на полный HP                            |
| K01 | Есть видимая цель → сравнить ожидаемый магический урон и угрозу с учётом сопротивлений                                   |
| K02 | Цель вне дальности → подойти под прикрытием, избегая доступного врагу ближнего удара                                     |
| K03 | Воздух угрожает базе → атаковать допустимую воздушную цель или занять позицию защиты                                     |
| K04 | Маг уязвим/бой проигрывается → отойти, не преследуя цель с высокой защитой                                               |
| F01 | Наземный обход долгий → разведать воздушным маршрутом, не раскрывая невидимые объекты заранее                            |
| F02 | Видна незащищённая экономика → рейд с учётом известных стрелков, башен и магов                                           |
| F03 | Базе нужна помощь → перехватить допустимую цель, сохранив законную конечную клетку                                       |
| F04 | На пути сильная противовоздушная защита → изменить маршрут или отступить                                                 |

Общие оценки сил S10/S13 должны учитывать возможность нанести урон цели,
сопротивления и доступное лечение. Нельзя считать непоражающий воздух отряд
достаточной защитой только по сумме его обычного урона.
