# Каталог поведения ИИ для MVP

[Основа ИИ](04-ai-core.md) · [Тактика новых ролей](07-ai-tactics.md) · [Карта этапов](../ROADMAP.md).
Здесь базовый каталог: 12 стратегий и 51 тактическое правило. Ещё 12 правил
H/K/F для лекаря, мага и летающего юнита — в
[дополнении S14a–S14b](06-magic-and-flight.md). Итого MVP: 63 тактических правила. Строка — самостоятельное проверяемое решение, а не обещание «умного ИИ».
Действие выбирается только при выполнении общих правил, наличии очков и видимости.

## Общая стратегия: G01–G12

| ID  | Когда полезно                                                    | Решение                                                   | Когда завершить/сменить                                |
| --- | ---------------------------------------------------------------- | --------------------------------------------------------- | ------------------------------------------------------ |
| G01 | База под непосредственной угрозой                                | Срочная оборона, отзыв ближайших войск, эвакуация рабочих | Угроза снята либо база потеряна                        |
| G02 | Доход не покрывает ближайший план                                | Перераспределить рабочих, восстановить добычу             | Дефицит закрыт либо возникла тревога                   |
| G03 | Домашняя экономика занята, есть безопасный ресурс                | Расширить добычу с разведкой и охраной                    | Новая точка работает либо путь опасен                  |
| G04 | Армии/населения не хватает для задачи                            | Фермы, производство и найм нужных ролей                   | Нужный состав получен либо изменился враг              |
| G05 | Вражеская база не найдена                                        | Разделить границы разведки между разведчиками             | Найдена база либо требуется отступление                |
| G06 | Нет известного доступного нужного ресурса                        | Искать ресурс и проход к нему                             | Найден пригодный участок                               |
| G07 | План основан на старом контакте                                  | Перепроверить последнее место врага                       | Контакт обновлён/опровергнут                           |
| G08 | Есть преимущество/окно атаки либо затянулся безопасный сбор      | Собрать ударную группу, выбрать цель и маршрут            | Цель уничтожена, угроза базе или потери выше порога    |
| G09 | Есть уязвимая экономика врага, фронтальное наступление невыгодно | Ограниченный рейд без оголения базы                       | Цель поражена, подход перекрыт или подходит защита     |
| G10 | Известно направление угрозы, но нет срочного штурма              | Гарнизон, прикрытие прохода, башня                        | Угроза выросла до G01 либо появилась возможность атаки |
| G11 | Группа проигрывает локальный бой                                 | Отход, безопасный сбор и восполнение потерь               | Группа боеспособна либо задача отменена                |
| G12 | Есть запас и ожидаемая польза улучшения                          | Кузница и исследование для экономики/армии                | Работа запущена либо резерв нужен для выживания        |

G01 имеет право прервать остальные планы. Остальные конкурируют по оценке
полезности; удержание текущего плана предотвращает метания. Профили меняют веса,
не доступ к информации. Пороги сравнения сил/риска — настройки, проверяемые в S21.

## Рабочий: W01–W10

| ID  | Условие → действие                                                                                                             |
| --- | ------------------------------------------------------------------------------------------------------------------------------ |
| W01 | В пределах известной опасности → снять назначение и уйти к защите; не пересекать огонь ради прежней задачи                     |
| W02 | Дефицит золота и доступное место → занять безопасный рудник                                                                    |
| W03 | Дефицит дерева и доступное место → занять безопасную лесопилку                                                                 |
| W04 | Нет места нужной добычи → исследовать безопасную границу в поиске ресурса до появления разведчика                              |
| W05 | Найден ресурс, есть бюджет и подход → построить добывающее здание и назначиться на работу                                      |
| W06 | Следующий найм упирается в население → построить ферму без перекрытия выходов                                                  |
| W07 | Стратегии нужно производство/защита/технология → построить казармы, конюшню, мастерскую, башню кузницу или Святилище по задаче |
| W08 | Важное своё здание повреждено и ремонт безопасен → отремонтировать, сохранив резерв найма                                      |
| W09 | Назначение потеряно из-за разрушения/опасности → снять резервы, восстановить или выбрать другую добычу                         |
| W10 | Своя позиция/постройка блокирует развитие → уступить клетку, сменить площадку либо запросить снос мешающего здания             |

## Мечник: M01–M06

| ID  | Условие → действие                                                                      |
| --- | --------------------------------------------------------------------------------------- |
| M01 | Враг угрожает базе/рабочим → перехватить ближайшую опасную цель                         |
| M02 | Ценный рабочий, стрелок или осада уязвимы → сопровождать и занимать прикрывающую клетку |
| M03 | Группа ещё собирается → идти к месту сбора, не атаковать в одиночку                     |
| M04 | Группа готова → наступать на назначенную цель, открывая путь стрелкам                   |
| M05 | Можно снять опасную цель общим фокусом → выбрать её с учётом уже запланированного урона |
| M06 | Мало HP/бой проигрывается → отступить к своим, если безопасный путь существует          |

## Лучник: A01–A07

| ID  | Условие → действие                                                                          |
| --- | ------------------------------------------------------------------------------------------- |
| A01 | Есть выбор огневых клеток → до атаки занять дальнюю клетку вне ближней угрозы               |
| A02 | Доступна опасная добиваемая цель → завершить её уничтожение без лишнего дублирования огня   |
| A03 | Несколько целей → предпочесть уязвимую пехоту/стрелка с высокой угрозой                     |
| A04 | Своя пехота наступает → держаться за прикрытием и поддержать фокус                          |
| A05 | База/рабочий под атакой → перейти на оборонительный огонь                                   |
| A06 | Цель вне дальности/скрылась → сменить позицию по последнему контакту без атаки сквозь туман |
| A07 | Ближний враг или низкое HP → отойти вместо выстрела, если это сохраняет юнита               |

«Выстрелил и убежал» в этих правилах отсутствует: после выстрела нет движения.

## Разведчик: R01–R06

| ID  | Условие → действие                                                                    |
| --- | ------------------------------------------------------------------------------------- |
| R01 | Есть непроверенная граница → раскрыть максимум новой территории за безопасный маршрут |
| R02 | Нужен ресурс → обследовать неизвестный сектор и известные подходы                     |
| R03 | Контакт устарел → проверить его последнее место и обновить память                     |
| R04 | Обнаружена вражеская группа → наблюдать с безопасного расстояния, обновлять угрозу    |
| R05 | Готовится наступление → проверить фланг и альтернативный подход                       |
| R06 | Обнаружена опасность/перехват → уклониться, не размениваться на случайную атаку       |

## Копейщик: P01–P05

| ID  | Условие → действие                                                                   |
| --- | ------------------------------------------------------------------------------------ |
| P01 | Видна опасная конница → перехватить её вместо далёкой обычной цели                   |
| P02 | Стрелки/осада под угрозой конницы → занять защитную позицию                          |
| P03 | Уязвим проход к базе/ресурсам → удерживать подход, не преследовать приманку          |
| P04 | Нет срочной защитной задачи → идти с ударной группой и атаковать доступную цель      |
| P05 | Окружение/низкое HP → отойти к прикрытию либо удержать проход, если отход невозможен |

## Всадник: C01–C06

| ID  | Условие → действие                                                                      |
| --- | --------------------------------------------------------------------------------------- |
| C01 | Рабочие/добыча врага без защиты → выполнить ограниченный рейд                           |
| C02 | У противника открытый фланг → обойти фронт и атаковать стрелков/осаду                   |
| C03 | Быстрый враг движется к своей экономике → перехватить                                   |
| C04 | Видимый ослабленный враг отступает → преследовать в пределах безопасного маршрута       |
| C05 | Нет боевой задачи, сектор не разведан → быстро проверить фланг, не заменяя всю разведку |
| C06 | Копейщики, сильная защита или низкое HP → разорвать контакт и сменить направление       |

## Осадная машина: O01–O06

| ID  | Условие → действие                                                                                |
| --- | ------------------------------------------------------------------------------------------------- |
| O01 | Планируется штурм → собраться с прикрытием, не уходить вперёд одной                               |
| O02 | Есть видимое важное здание в дальности → обстрелять башню/производство/ратушу по цели операции    |
| O03 | Нет огневой позиции → занять доступную клетку в дальности и вне известной ближней угрозы          |
| O04 | Сопровождение отстало → ждать в безопасной точке до срока пересмотра                              |
| O05 | Подошёл мобильный враг → отступить к прикрытию, при невозможности выбрать законную защитную атаку |
| O06 | Цель разрушена/скрылась, проход закрыт → переоценить следующую цель или запросить разведку        |

## Башня: T01–T05

| ID  | Условие → действие                                                                           |
| --- | -------------------------------------------------------------------------------------------- |
| T01 | Ратуше грозит немедленный урон → атаковать источник угрозы в своей дальности                 |
| T02 | Можно уничтожить опасную цель → добить её, учитывая общий фокус                              |
| T03 | Осадная машина угрожает обороне → приоритетно бить её, если она видима и достижима огнём     |
| T04 | Рабочие/стрелки атакованы → прикрыть их выстрелом по нападающему                             |
| T05 | Нет законной видимой цели → сохранить действие до пересмотра, не атаковать контакт из памяти |

## Как добавлять и проверять правило

Каждому ID соответствуют сценарии: условия выполнены → осмысленное действие;
условия не выполнены → отказ; конфликт с более срочной задачей → корректный приоритет.
Общие проверки отдельно доказывают законность действий и отсутствие скрытого знания.
Если действие отклонено, задача освобождает резервы и выбирает fallback:
новая цель → безопасное ожидание → завершение хода, без бесконечного повтора.
