# S14. Расширение войск и зданий

[Карта этапов](../ROADMAP.md). Ниже — план разработки MVP.

## Состояние реализации

| Часть      | Состояние                                                                                                                                                         |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Юниты      | Разведчик (ратуша), копейщик (казармы), всадник (конюшня), осадная машина (мастерская): цена, HP, население, очки, обзор, дальность, рисунок и карточки.          |
| Здания     | Конюшня и мастерская нанимают; кузница строится с ролью `research`, работ не запускает до S16.                                                                    |
| Урон       | Общая формула: атака + бонус против категории − броня, минимум 1; категории пехота, стрелки, конница, осада, рабочие, здания. Ожидаемый урон — при наведении.     |
| Удар осады | Подготовка по разведанной клетке 2–5, исполнение в начале следующего своего хода, урон своим, лес → поле, публичная отметка без раскрытия орудия, отмена гибелью. |
| ИИ         | Отметки ударов в наблюдении (`strikes`); найм и тактика новых юнитов — S15.                                                                                       |

Принятые решения: стартовые числа — в [units.md](../units.md) и
[buildings.md](../buildings.md), подбираются в S21. Брони и бонусов у прежних
юнитов и зданий нет, чтобы их бой не изменился. Осадная машина бьёт только
подготовленным ударом, без прямой атаки. Ход, в котором орудие готовит удар,
заканчивает его движение, поэтому отмена движением в текущих правилах
недостижима; отмена гибелью работает.

Проверено: unit-тесты формулы урона, состава, законных пар здание/юнит,
начальных очков и контрролей в дуэли; интеграционные сценарии удара
(`src/app/game/siege.integration.test.ts`): ход владельца при трёх сторонах,
отсутствие повтора, уход цели, урон своим, лес, бонус по зданию, отметка
у всех при скрытом орудии, снятие при гибели, конец партии, отказы.
В браузере (1280×720, «Большая», сид 7): найм разведчика, постройка
мастерской, найм осадной машины, подготовка и исполнение удара.
Проверки «осада здания под прикрытием» и «разведчик с обзором» в партии
не проводились.

## S14. Базовое расширение: 7 юнитов и 9 зданий

Зависимости: S08, S13. Ориентиры: конфигурация, создание объектов, команды,
меню найма/строительства, отрисовка и справочники.

Это промежуточный состав: S14a–S14b добавят мага, лекаря, летающего юнита
и Святилище; итог MVP — 10 юнитов и 10 зданий.
Сохраняются рабочий, мечник, лучник и шесть исходных зданий.
Добавляются следующие роли, а не только версии старых юнитов с большим HP:

| Новый юнит     | Где нанять | Роль и ограничение                                                    |
| -------------- | ---------- | --------------------------------------------------------------------- |
| Разведчик      | Ратуша     | Большой обзор и мобильность, слабый бой; ищет цели и ресурсы          |
| Копейщик       | Казармы    | Бонус против конницы, защита стрелков; уступает мечнику в обычном бою |
| Всадник        | Конюшня    | Быстрый рейд по рабочим/стрелкам; уязвим для копейщиков               |
| Осадная машина | Мастерская | Дальний урон по зданиям; медленная и слабая против мобильных войск    |

| Новое здание | Назначение                                        |
| ------------ | ------------------------------------------------- |
| Конюшня      | Найм всадника                                     |
| Мастерская   | Найм осадной машины                               |
| Кузница      | Исследования S16, одна активная работа на сторону |

- До добавления в меню задать для каждого объекта цену, HP, население, очки,
  обзор, дальность, требования и силуэт. Не смешивать радиус обзора с боем.
- Использовать общую формулу урона с небольшим набором категорий целей:
  базовый урон + явный бонус против категории − броня, минимум 1.
  Это первый физический расчёт; в S14a явно расширить его типами урона и
  соответствующей защитой. Показывать ожидаемый урон; формула одна для всех сторон.
- В MVP без кругового урона, перевозки, скрытности и отдельной фазы развёртывания.
  Дифференциация строится на дальности, мобильности, обзоре и контрролях.
- Существующие здания тоже остаются полезными: ресурсные обеспечивают экономику,
  ферма увеличивает население, башня защищает, казармы дают основную пехоту.
- Обновить доступность строительства и найма, карточки, примитивную графику,
  сериализуемые типы и справочники. Финальная графика придёт в S18.

### Читаемый подготовленный удар (обязательная часть S14)

- Осадная машина готовит удар по выбранной клетке на следующий свой ход.
  Одно действие подготовки и один отложенный удар; цель не следует за ушедшим
  юнитом. Движение или уничтожение орудия отменяет подготовку.
- Исполнять через общие команды и цикл ходов по контракту S01: однократно,
  с проверкой исполнителя, фазы, допустимости цели и исхода партии.
  Общий режим одновременных ходов и отдельная фаза развёртывания не нужны.
- Отметка клетки удара публична: её видят все участники независимо от тумана
  (исключение — исследование Скрытая наводка S16).
  Позиция, тип и HP орудия отметкой не раскрываются. Отмена снимает отметку у всех.
  Детали — [контракт правил](rules-contract.md#подготовленный-удар-осады-s14).
- Защитник может покинуть клетку, рискнуть удержать позицию или атаковать орудие;
  атакующий выбирает здание либо предполагаемый маршрут. Урон своим — по S01.
  Сохранить ограничение без кругового урона; не компенсировать задержку огромным AoE.

**Подсказки:** начать со сцены «орудие с охраной против армии у прохода»;
хранить минимальное отложенное действие, пригодное для S20, без общей системы очередей.
**Unit-тесты:** следующий ход именно владельца при трёх сторонах, отсутствие
повторного удара, уход цели, отмена движением/смертью, урон своим по контракту,
завершение партии, отметка у всех участников при скрытом орудии, снятие при отмене.
**Готово дополнительно для S14:** игрок может подготовить удар и сорвать вражеский;
маркер виден всем и не раскрывает орудие. Тактику ИИ завершить в S15.

**Подсказки:** проведи один новый тип через создание, меню, команду, отображение
и сохранение; после этого расширяй остальные. При выборе контрролей сравни
предсказуемые небольшие бонусы с количеством исключений в общей формуле.
**Unit-тесты:** законные пары здание/юнит, стоимость и начальные действия,
бонус против нужной категории, нижняя граница урона, независимость конфигурации.

**Готово:** все 7 типов нанимаются и все 9 зданий доступны по правилам;
каждая новая роль даёт проверяемое преимущество и имеет противодействие.
**Проверить:** конница против стрелка/копейщика, копейщик против мечника,
осада здания под прикрытием, разведчик с расширенным обзором.
