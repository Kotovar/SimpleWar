# SimpleWar

Simple Wars — браузерная пошаговая стратегия на квадратной карте. Игрок
развивает базу, строит здания, нанимает войска и побеждает, уничтожив ратушу
противника.

**Версия 1.0.0 — MVP:** одиночная партия против ИИ с профилями и уровнями
сложности, туман войны, 10 типов юнитов, 11 зданий и 5 исследований, магия,
летающий юнит и осада, сохранения, обучение, звук и музыка. Дальнейшие
расширения — в [плане после MVP](docs/post-mvp/README.md).

Клиент написан на React, TypeScript и Zustand с Immer. Карта и объекты
рисуются на Canvas; сборку и тесты запускает Vite+.

## Запуск

Нужны Node.js и pnpm. Версия pnpm задана в `package.json`.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

## Проверки

```sh
pnpm type-check
pnpm lint
pnpm test
pnpm build
pnpm fsd-check
```
